## Why This History Is Quarantined

The earlier route surfaces are useful for auditing how the final result was
obtained, but placing their detailed dispatch or constants inside a current
status narrative creates a second publication topology. A reader should reach
the current theorem without first deciding which historical route description
is authoritative. Current-public documents therefore link here without
repeating this detailed chronology.

Exact immutable June snapshot lines are governed separately by
`docs/internal/PUBLICATION_DOCUMENT_ROLES.json`. Audit reports and acceptance
matrices have the `audit-evidence` role. Neither compatibility placement nor an
audit directory grants an exception for a removed public alias.
