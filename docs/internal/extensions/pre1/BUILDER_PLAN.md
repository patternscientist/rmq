### 2.2 Memory layout and phases

Layout (addresses grow only by `reserve`, extent is monotone): `[0, extent₀)` supplied numeric input (extent₀ = n+1 word model, 1 comparison model; the n comparison-model keys live in the key bank and are counted as supplied input cells, CONTRACT.md:54-56) | `[extent₀, bufBase)` size-only temporary arrays (reserved in P1: stack S (n), ld (n), count (n), pos (n+1), running-rank arrays, super/local flag arrays, per-block excess min/max/argmin arrays (blockCount+1 each), local/global sparse memo arrays, `openCounts` scratch) | `[bufBase, outBase)` the bit buffer (one 0/1 cell per bit of `densePad W (packedReviewerPaddedBits shape)`) | `[outBase, extent)` the output words. `outBase` is returned by `halt OUT`. The BP bits are written directly into the buffer (no separate 2n array): the buffer's first `oldW` cells are reserved-and-zeroed for the header and patched with `natToBitsLE oldW lc` once lc is known (a second store; the final memory is what exactness reads).

Phases after the header load: P0 geometry prelude (S2) · P1 reserve arrays · P2 Cartesian stack pass and `openCounts` BP emission into the buffer (S3) · P3 excess sweep, block statistics, memoized sparse tables, summary/local/global/level tables into the buffer? — no: the close component comes after the access component in the payload (FlatPayload.lean:1877-1879), so P3 computes the interior tables into temporaries/registers only where needed and its emission happens after the access half. Concretely: P3a pos/rank/flag pass (needs only BP bits), lc, sc; P3b emit the 18 access sources; P4 excess sweep + block stats + memo arrays; emit the eight interior tables; P5 microtables; header patch; old zero padding; new zero padding (S6) · P6 output: 174 metadata words then Horner-packed dense words; `halt OUT` (S7). The **proof** order (stage schedule) is risk-first and differs from execution order; each phase block is verified independently against its own precondition, then composed by `Eval` sequencing.

Base register for temporaries: the first `reserve` after the header load returns `extent₀` into a register; every array base is that register plus a size-only offset. No program text depends on `extent₀`, so the same source works in both models.

## 4. Stage details

### S0 Foundations

1. `Program.lean`/`Calculus.lean` as in 2.1. The faulting transition IS recorded (its `after` has `.fault`); the next `stepProgram` is `none` (Model.lean:100-104). `RunsTo.fuel_extension` for halted or faulted finals. Positional provenance: `run_write_at : transitions[k]? = some t → t.instruction.primitive = .store a v → t.before = (run k s₀).final ∧ t.before.regs a < t.before.extent ∧ t.after.memory (t.before.regs a) = some (t.before.regs v)` (Primitive.lean:143-146, 183-186).
2. `run_eq_of_agree` (fine form). ## 6. Cost, workspace and the closed blind spots

### 6.1 Work
Work is `Run.steps` of the frozen interpreter (transitions through `checkedStep`), never a counter. Per-block `Eval` costs are exact (`compile_realizes` transports `k` as `ts.length`); loop costs come from `Eval.loop_iterate(_potential)` with iteration counts `n`, `2n`, or size-only counts bounded by `Spec/Envelope.lean`; the final sum is `C·n + D` with `C := Σ aₖ`, `D := Σ bₖ` reduced to numerals (`norm_num`/`decide`) and pinned by `rfl` in consumers. Fuel = `C·n + D`; `builder_halts` + `fuel_extension` make the run fuel-insensitive (FK-15, ATTACK_TABLE.md:30). Category partition is a generic lemma.

### 6.2 Workspace
Extent is monotone; temporaries = size-only arrays + bit buffer; all bounded by Envelope; input, code, registers, output, and historical peak reported separately. The comparison model's key bank (n cells) is named in the input account; the base of the temporaries is `extent₀`, taken from the first reserve, never assumed.

### 6.3 Fault-freedom and safety
`Prim.Safe` includes store/load extent and initialized-cell obligations and key presence; stage theorems are stated as `SafeEval` (post-status running, every executed action safe), so a truncated run cannot masquerade as a shorter successful one. Composition across the ~10 phases is by `Eval` sequencing; no per-phase ad hoc bound.

### 6.4 INV-GLOBAL-PHYSICAL-MACHINE (honest statement)
The join proves: (a) the builder's final store restricted to `[outBase, extent)` equals `buildMemory xs` cell by cell with positional store provenance for every output cell; (b) the accepted PQ1 query theorem over the list `efficientBuild xs = buildMemory xs`; (c) a lifted Conservative simulation of the accepted query program on `Conservative.state (efficientBuild xs) _` in the new ISA. It does **not** claim an offset-relocated single-store execution of the query at `outBase` inside the builder's memory (the query computes addresses dynamically; relocation would need a distinct program). The coordinator must accept this reading or require relocation (open question 3).

### 6.5 Controls that are proof-level, not fixture-level
With C in the hundreds, a quadratic mutant at n ≤ 64 need not exceed `C·n + D`; the repeated-prefix/quadratic control is realized primarily as a registry case whose producer cost theorem (`pass2_cost`/`stackPass_cost`) fails to elaborate; the runtime cost check at n = 64 is recorded as informative. Table/program payload bypass (a baked constant table) is caught by the builder firewall (a literal list in `Builder/*` that is not generated is rejected by review + `Uniform` is unaffected, so the primary surface is the exactness theorem failing for a second input size and the firewall's hash change); hidden semantic call is the firewall import surface.

### 6.6 Gate runtime
Every module gets a recorded focused-build time under `LEAN_NUM_THREADS=1`; a module exceeding 600 s is split before proceeding; `rfl` pins are stated on the compiled list only (never on unrolled source); no `decide` over the full 174-word metadata at n = 24 in proofs (executables do that). The builder replay is the focused gate; the aggregate (already >14,400 s once, REPORT.md:125-132) is coordinator-scheduled on the frozen candidate; a timed-out aggregate is not PASS.
