## Intended proof chain

Primitive execution on the counted physical allocation -> exact packed-read/control refinement -> canonical whole-query value -> ordinary `List Int` leftmost-minimum contract. Each arrow must constrain returned values and ordered receipts of the actual run, with one consistent allocation after any metadata repair. Cost must follow that same run. The new theorem cannot assume its own semantic correctness, readiness, width, or budget as a premise.

The most useful skeptical check is to ask for the exact evaluator equality linking the output register to the memory whose entire allocation the space theorem counts. Existing successful component proofs over different evaluators or memories do not supply that equality by conjunction.
